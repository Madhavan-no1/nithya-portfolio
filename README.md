# Dr. Nithyakalyani Krishnan: Portfolio

Academic portfolio for Dr. Nithyakalyani Krishnan, Assistant Professor, Department of Biomedical Engineering, SRM Institute of Science and Technology.

A static site: plain HTML, CSS and JS with no build step.

```
index.html        page content
css/style.css     styles
js/main.js        navigation, scroll reveals, publication filter
assets/           portrait, favicon
```

To preview locally, run `python -m http.server` in this folder and open http://localhost:8000.
